## 概述与范围

AlphaSignal 是一款**个人使用**的美股分析及交易策略构建工具。本软件**不**用于商业用途，**不**构成投资建议，也**不**适用于日内交易。系统基于日线数据运行，仅供个人研究使用。应用程序对可配置的美股池运行8个维度的反转/动量评分引擎，允许用户调整各指标权重和阈值，并对历史数据进行策略回测。

---

### 交易股票池

| 股票池 | 包含内容 | 说明 |
|--------|----------|------|
| 标普500 | 当前标普500成分股 | 从维基百科获取，本地缓存 |
| 标普中盘400 | 当前标普400成分股 | "标普1000"组成部分 |
| 标普小盘600 | 当前标普600成分股 | "标普1000"组成部分 |
| 纳斯达克100 | 当前纳斯达克100成分股 | 可单独选择；不包含在"全部股票池"中 |
| 全部股票池 | 标普500 ∪ 中盘400 ∪ 小盘600 ∪ 自选股，去重 | 默认扫描股票池 |
| 自选股 | 用户自定义股票（在设置中添加/删除） | 始终包含在"全部股票池"中 |

> **注意：** 成分股列表反映的是*当前*的指数成员。未追踪历史时点成员数据（解决幸存者偏差所必需），详见回测说明。

### 系统架构

```
浏览器
  └─ React 18 + Vite + TypeScript 单页应用
        ↕ HTTP (REST JSON)
Python FastAPI 后端（端口8000）
  ├─ 信号引擎  （pandas-ta指标 → 8维度综合评分）
  ├─ 回测引擎  （滚动投资组合模拟）
  ├─ APScheduler  （可选每日自动扫描）
  └─ 存储
        ├─ SQLite  （运行记录、信号、自选股、回测结果）
        └─ Parquet  （价格K线缓存，每只股票一个文件）
```

**后端：** Python 3.11+、FastAPI、uvicorn、pandas、pandas-ta、numpy、yfinance、pydantic v2、PyYAML、SQLAlchemy/SQLite、pyarrow、httpx、APScheduler

**前端：** React 18、Vite、TypeScript、Tailwind CSS、lightweight-charts（TradingView授权图表组件）、TanStack Query、react-router-dom、SheetJS（xlsx导出）

**每日流程：** APScheduler（或手动触发）→ 获取/更新Parquet价格缓存 → 计算每只股票的8维度综合评分 → 存入SQLite → 前端按需获取

## 策略详情

AlphaSignal 实现了两种互补的波段交易策略 — **多头**（顺势做多）和**空头**（通过反向ETF顺势做空）。两种策略均基于日线数据运行。

---

### 多头策略

在确立的上升趋势中，于**更高的低点回调处**（即上升趋势中支撑位的再测）买入标的股票，在综合评分转为看空时（表明回调结束或趋势反转）退出持仓。

- 基于**多头**评分配置，对标的股票本身计算信号
- 直接买入股票（无杠杆）
- 目标：在上升趋势的波段低点入场，在波段高点附近出场

### 空头策略

通过**买入对应的单股反向ETF**（而非做空股票本身）来获利于确认的下降趋势，无需融券或保证金要求。

- 使用**空头**评分配置对**标的股票**计算信号（寻找看跌形态）
- 在**反向ETF**上执行实际交易（如QQQ对应SQQQ）
- 重要提示：带有每日重置杠杆的单股反向ETF，在多日持仓中会产生**损耗**，实际收益将偏离理论上的 −1× 标的收益

---

### 评分系统

8个组件各自从不同维度评估价格行为，每个输出的子评分范围为 **[−100, +100]**，综合评分为加权平均值：

> **综合评分 = Σ（子评分 × 权重/100）**，再经市场环境过滤

#### 组件权重（按 config.yaml 配置）

| 组件 | 权重 | 衡量内容 |
|------|:----:|---------|
| K线形态 | 12% | 单根K线形态：锤子线、吞没、十字星、纺锤线 |
| 3根K线形态 (P3) | 8% | 支撑/阻力位的3根K线反转与持续形态 |
| 5根K线形态 (P5) | 12% | 5根K线波段结构：反转与趋势确认 |
| 成交量 | 10% | 相对成交量 vs 30日均量（映射到±100） |
| EMA系统 | 15% | EMA-20/50/100/200排列顺序 + 近期金叉/死叉 |
| 支撑/阻力 | 15% | 与支撑阻力位的距离；反弹与突破 |
| MACD | 18% | MACD金叉/死叉、柱状图方向、背离 |
| RSI | 10% | RSI区间（超买/超卖）+ 30/70穿越 |
| **合计** | **100%** | |

*多头和空头配置的权重默认相同。*

---

### 信号阈值（按 config.yaml 配置）

| 信号 | 多头配置 | 空头配置 |
|------|:--------:|:--------:|
| 强力买入 | ≥ 60 | ≥ 85 |
| 买入 | ≥ 50 | ≥ 70 |
| 持有 | −50 至 +50 | −70 至 +70 |
| 卖出 | ≤ −50 | ≤ −70 |
| 强力卖出 | ≤ −60 | ≤ −85 |

> 空头配置采用更宽的阈值（±70/±85），要求出现更强的看跌信号才会触发交易，因为反向ETF交易存在额外的损耗风险。

---

### 市场环境过滤（EMA-200）

在执行任何信号前，系统会使用200日均线检查**每只股票**的市场环境：

- **看涨环境**：价格在EMA-200上方，且EMA-200斜率（过去20根K线）向上 → 允许多头信号
- **看跌环境**：价格在EMA-200下方，且EMA-200斜率向下 → 允许空头信号
- 若两种环境均未确认，该股票不产生多头或空头信号

这确保了系统**永不逆势操作**。

---

### 策略局限性

- **仅适用于日线时间框架** — 无法预测盘中走势，也无法在交易日内对新闻做出反应
- **震荡市场风险**：在无明确趋势的横盘市场中，信号可能频繁反复；EMA-200过滤器可减少但无法完全消除此问题
- **反向ETF损耗**：多日持仓时，实际ETF收益与理论 −1× 标的收益的偏差会逐渐累积
- **权重与阈值经人工调整** — 可能过度拟合回测周期
- **不具备基本面分析能力** — 财报超预期、业绩指引变化及宏观事件均不在模型考量范围内（仅提供可选的财报前禁止交易功能）
- **EMA-200环境判断存在滞后** — 真实趋势反转首日不会触发环境切换

## 回测详情与局限性

回测引擎模拟一个滚动投资组合 — 按时间顺序逐日处理，仅使用截至当日收盘时可获得的信息，在*次日*开盘时成交。

---

### 回测运作方式

#### 信号与成交时序（无未来数据）

> **第T根K线**的信号仅使用第0至T根K线的数据（无未来信息）。
> 买入和卖出订单在**第T+1根K线开盘价**成交。

#### 投资组合模拟

| 参数 | 默认值（按 config.yaml 配置） |
|------|:---:|
| 初始资金 | $100,000 |
| 仓位大小 | 每笔持仓占当前净值的8% |
| 最低仓位规模 | $2,000 |
| 单只股票资金上限 | 净值的30% |
| 最大同时持仓数量 | 15 |
| 每日最多选入候选股 | 10（按综合评分排名） |
| ATR止损倍数 | 1.5 × 14周期ATR |
| 移动止损 | 是 — 随持仓盈利向有利方向移动 |
| 止损出局后冷却期 | 5根K线内不再重新入场 |

**入场选股：** 每日对所有新出现的买入/强力买入信号（多头）或卖出/强力卖出信号（空头）按综合评分排名，仅取前10名进入槽位和资金校验，次日开盘成交。

**出场条件：**
- 盘中**ATR止损**触发（基于日线高低价检查）→ 以止损价成交，若跳空则以开盘价成交
- 持仓股**出现反向信号** → 次日开盘成交
- **数据结束** → 以最后一根K线收盘价平仓

#### 费用（按 config.yaml 配置）

| 参数 | 数值 |
|------|:----:|
| 每股费用 | $0.005 |
| 每笔最低费用 | $1.00 |
| 每笔最高费用 | 交易金额的1% |
| 收费时机 | 买入**和**卖出各收一次 |
| 滑点 | 成交价的0.1% |

#### 基准

从第一个可用开盘价开始**买入持有QQQ**，持有至回测期末。收益使用经复权的全收益价格（含股息），与策略收益具有可比性。

#### 价格基准

策略和基准均使用**yfinance复权价格**（`auto_adjust=True`）— 历史价格已针对拆股和股息进行调整，收益率反映含股息的总回报。

---

### 回测局限性

- **数据延迟与精度：** 仅支持日线K线；yfinance数据最长可能延迟约1小时。不适合当日决策或盘中择时。

- **回测时间窗口限制：** 默认5年回测。需要预热数据的指标（如EMA-200需要200根K线）会缩短前期的有效交易历史。yfinance通常可提供大盘股20年以上的日线数据。

- **空头侧历史数据不足：** 单股反向ETF大多在2022年后才推出，多数标的仅有1–3年的ETF历史，严重限制了空头侧的回测窗口。系统会生成覆盖率报告，显示哪些标的可测试及其日期范围。

- **幸存者偏差（重要）：**
  标普500、中盘400和小盘600的成分股列表反映的是*当前*成员 — 即今日仍在指数中的公司。在回测期间被**退市、破产或从指数中剔除**的公司不在测试范围内。
  
  **示例：** 用今日500只成分股对"标普500过去5年"进行回测，只测试了在5年内*持续留在*指数中的公司。那些期间被剔除的公司（往往是因为业绩大幅下滑）被排除在外。这使回测结果看起来比实际情况更好 — 产生"虚假美化"的向上偏差。
  
  修正此问题需要历史时点的指数成员数据（免费渠道不可获得）。请将所有回测收益视为**乐观的上限估计**。

- **反向ETF损耗导致空头收益虚高：** 单股反向ETF每日重置杠杆。多日持仓后，ETF的实际表现会落后于（或高估相对于）理论 −1× 标的收益。回测在有ETF历史数据的情况下使用真实ETF损益，但有限的ETF历史意味着标的较长历史中的许多空头信号无法回测。

- **不含流动性或市场冲击模型：** 小盘股中的薄流动性股票可能有较宽的买卖价差。0.1%的滑点假设对低流动性标的可能过于乐观。

- **不含融券成本或税务计算。**

- **公司行动**仅通过复权价格处理。合并、分拆和代码变更可能导致数据缺失或不连续。

- **历史表现不代表未来结果。本回测仅用于个人研究和策略理解，不构成任何投资建议。**
