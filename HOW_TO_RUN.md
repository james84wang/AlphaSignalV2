# How to run these prompts

1. Put this whole `prompts/` folder inside your project folder
   (e.g. ~/projects/alphasignal/prompts).
2. Also copy `CLAUDE.md` to the PROJECT ROOT (one level up, next to where the code lives).
   Claude Code reads CLAUDE.md automatically every session.
3. Open Terminal, `cd` into the project folder, run `claude`.
4. For each phase, type one line:  Read prompts/phase-0.md and execute it.
5. Approve actions when asked. When it reports done, start a fresh session (type /clear)
   and do the next phase.

Order: phase-0 -> phase-1 -> ... -> phase-7. Run them in order.
