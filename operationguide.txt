SECTION 2 — HOW TO START THE APP  (your everyday launch steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1 — Open Terminal
  • Press Command + Space to open Spotlight
  • Type "Terminal" and press Enter

Step 2 — Navigate to the project folder
  Copy and paste this line into Terminal, then press Enter:

    cd /Users/jameswang/Documents/Claude/Code/AlphaSignalV2

Step 3 — Launch the app
  Copy and paste this line into Terminal, then press Enter:

    bash scripts/launch.sh

  What happens next:
  • The terminal will show a few lines of startup text — that is normal.
  • After about 2–3 seconds, the app opens automatically in a Chrome window
    (with no address bar, so it looks like a standalone desktop app).
  • If Chrome is not installed, it will open in Safari instead.

Step 4 — Use the app
  The app opens at http://localhost:8000
  You will see four pages in the left sidebar:
    • Dashboard   — ranked list of signals for your watchlist
    • Symbol      — price chart + score breakdown for one stock
    • Settings    — adjust strategy weights
    • Backtest    — run a historical backtest

Step 5 — Stop the app when you are done
  Click back on the Terminal window and press:

    Control + C

  This shuts down the server. You can close the Terminal window after that.

SECTION 3 — RUNNING THE DAILY SIGNAL SCAN MANUALLY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The daily scan downloads the latest market data, scores every stock on your
watchlist, and saves the results to the database.

You can trigger it manually at any time (after US market close, 4 PM ET):

Step 1 — Open Terminal and navigate to the project folder
  (Same as Section 2, Steps 1 and 2 above)

Step 2 — Activate the Python environment
  Copy and paste this line, then press Enter:

    source .venv/bin/activate

  You will see (.venv) appear at the start of your terminal prompt. That means
  it worked.

Step 3 — Run the daily scan
  Copy and paste this line, then press Enter:

    python scripts/run_daily.py

  The scan takes 1–3 minutes depending on how many stocks are in your watchlist.
  When it finishes, you will see a ranked table of signals printed in the terminal.

Step 4 — View the results in the app
  Start the app (Section 2) and open the Dashboard page.
  The fresh signals will be shown there automatically.

SECTION 4 — YOUR WATCHLIST  (which stocks get analysed)

Your watchlist lives in this file:
  /Users/jameswang/Documents/Claude/Code/AlphaSignalV2/data/watchlist.csv

To add or remove stocks:

Step 1 — Open the file in TextEdit
  • Open Finder
  • Press Command + Shift + G
  • Paste this path and press Enter:
      /Users/jameswang/Documents/Claude/Code/AlphaSignalV2/data
  • Double-click watchlist.csv

Step 2 — Edit the list
  The file looks like this:

    symbol,exchange
    AAPL,NASDAQ
    MSFT,NASDAQ
    NVDA,NASDAQ

  • To ADD a stock: type a new line with the ticker and exchange
  • To REMOVE a stock: delete that line
  • Save the file (Command + S)

  Common exchanges: NASDAQ, NYSE

Step 3 — Run the daily scan again
  After changing the watchlist, run the scan once (Section 3) so the new
  stocks get downloaded and scored.

SECTION 5 — AUTOMATIC DAILY SCAN  (runs every morning without you lifting a finger)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You can set up your Mac to run the scan automatically at 8 AM every Tuesday
through Saturday. That way the results are ready for you each morning.

IMPORTANT: Your Mac must be awake (not shut down) at 8 AM for this to work.
If your Mac sleeps, enable "Wake for network access" in System Settings →
Battery, or simply plug it in overnight.

Step 1 — Open Terminal and run this command to open your schedule list:

    crontab -e

  This opens a text editor called "vi". Do not panic — follow the steps below.

Step 2 — Press the letter  i  on your keyboard (this switches to typing mode)

Step 3 — Type this line exactly (or copy-paste it):

    0 8 * * 2-6 /Users/jameswang/Documents/Claude/Code/AlphaSignalV2/scripts/run_daily_cron.sh >> /Users/jameswang/Documents/Claude/Code/data/daily_run.log 2>&1

Step 4 — Press Escape on your keyboard

Step 5 — Type  :wq  (colon, then w, then q) and press Enter
  This saves the file and exits.

Step 6 — Confirm it was saved by running:

    crontab -l

  You should see the line you just typed printed back at you.

Step 7 — Grant permissions (macOS security requirement)
  • Open System Settings
  • Go to Privacy & Security → Full Disk Access
  • Click the + button
  • Press Command + Shift + G, type /usr/sbin/ and press Enter
  • Select the file called "cron" and click Open
  • Make sure the toggle next to cron is turned ON

Step 8 — Check the log the next morning to confirm it ran:

    tail -50 /Users/jameswang/Documents/Claude/Code/data/daily_run.log

  You should see a ranked signal table at the bottom of the log.

SECTION 6 — FRESH INSTALL ON A NEW MAC  (only if starting from scratch)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Skip this section unless you are setting up on a brand new machine.

Step 1 — Install Homebrew (Mac package manager)
  Open Terminal and paste this, then press Enter:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/homebrew/install/HEAD/install.sh)"

Step 2 — Install Python 3.11

    brew install python@3.11

Step 3 — Install Node.js

    brew install node

Step 4 — Copy the project folder to:
  /Users/YOUR_USERNAME/Documents/Claude/Code/AlphaSignalV2

Step 5 — Navigate to the project folder

    cd /Users/YOUR_USERNAME/Documents/Claude/Code/AlphaSignalV2

Step 6 — Create the Python environment

    python3.11 -m venv .venv
    source .venv/bin/activate
    pip install -e ".[dev]"

Step 7 — Install frontend packages

    cd frontend
    npm install
    cd ..

Step 8 — Build the frontend

    cd frontend
    npm run build
    cd ..

Step 9 — You are ready. Follow Section 2 to launch the app.
